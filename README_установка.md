# Смена+ — обучающее приложение с геймификацией

## Что внутри архива
- `index.html`, `styles.css`, `data.js`, `app.js` — само приложение
- `manifest.json`, `sw.js` — делают его устанавливаемым PWA (иконка на главном экране, офлайн-работа)
- `icons/` — иконки приложения

## Как установить на Android (коротко)
Файлы нужно разместить на любом HTTPS-хостинге — Android не позволяет установить PWA прямо с диска (`file://`).

**Самый быстрый бесплатный способ — GitHub Pages:**
1. Создайте новый репозиторий на GitHub, загрузите туда все файлы из этого архива (сохраняя структуру папок).
2. В настройках репозитория → Pages → Source выберите ветку `main` и папку `/root`.
3. Через 1–2 минуты сайт будет доступен по адресу вида `https://ваш-логин.github.io/название-репозитория/`.
4. Откройте эту ссылку в Chrome на Android → появится баннер «Добавить на главный экран» (или через меню ⋮ → «Установить приложение»).

**Альтернативы:** Netlify Drop (netlify.com/drop — просто перетащить папку), Vercel, Firebase Hosting — все работают аналогично и тоже бесплатны для такого объёма.

## Как редактировать содержимое курсов
Внутри самого приложения: Профиль → «Режим редактирования» → «Включить» → PIN **1234**.
После включения на карточках курсов и модулей появляются значки ✏️ — можно добавлять/редактировать/удалять курсы, уроки и тесты прямо с телефона. Изменения сохраняются на устройстве (localStorage), у каждого пользователя — свои.

Если нужно, чтобы контент был единым для всех пользователей (не редактировался у каждого локально), это отдельная доработка — потребуется простой backend (например, Firebase) вместо localStorage. Дайте знать, если такой сценарий актуален.

## Смена PIN редактора
В файле `app.js` найдите строку `if (pin !== "1234")` и замените на нужный PIN.

## Технические детали
- Работает полностью офлайн после первого открытия (service worker кеширует всё).
- Данные (прогресс, XP, значки, отредактированный контент) хранятся в localStorage браузера на устройстве.
- Формат вопросов теста — JSON, редактируется через форму в самом приложении (поле «Вопросы»).
