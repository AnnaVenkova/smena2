# Смена+ — обучающее приложение с геймификацией

## Что внутри архива
- `index.html`, `styles.css`, `data.js`, `app.js`, `cloud.js` — само приложение
- `manifest.json`, `sw.js` — делают его устанавливаемым PWA (иконка на главном экране, офлайн-работа)
- `icons/` — иконки приложения
- `firebase-config.js` — сюда вставляются ключи Firebase (для общего прогресса и админ-панели)
- `firestore.rules.txt` — правила безопасности для копирования в Firebase
- `sheets-config.js`, `apps-script.txt` — для выгрузки результатов в Google Таблицу

## Как установить на Android (коротко)
Файлы нужно разместить на любом HTTPS-хостинге — Android не позволяет установить PWA прямо с диска.

**GitHub Pages (то, что вы уже настроили):**
Просто загрузите все файлы из этого архива в ваш репозиторий (замените старые), сохраняя структуру папок — через 1–2 минуты сайт обновится по тому же адресу.

## Как редактировать содержимое (курсы, портал, тесты)
Внутри приложения: Профиль → «Режим администратора» → «Включить» → PIN **1234**.
После включения появляются значки ✏️ на курсах, модулях и материалах портала — можно всё редактировать прямо с телефона.

## Общий прогресс и админ-панель (Firebase)

Без этого шага у каждого пользователя прогресс хранится только в его браузере, и увидеть чужой прогресс нельзя.

1. Зайдите на **console.firebase.google.com** → «Add project» → создайте проект (бесплатно, аналитику можно отключить).
2. В проекте: **Build → Firestore Database → Create database** → «Start in test mode» → выберите ближайший регион.
3. Откройте вкладку **Rules** в Firestore → удалите содержимое → вставьте текст из файла `firestore.rules.txt` → **Publish**.
4. **Project settings** (шестерёнка вверху слева) → вкладка **General** → раздел «Your apps» → нажмите иконку `</>` (Web) → впишите любое имя → «Register app».
5. Firebase покажет объект `firebaseConfig` — скопируйте его целиком.
6. Откройте файл `firebase-config.js`, замените `const FIREBASE_CONFIG = null;` на скопированный объект (пример есть в комментариях внутри файла).
7. Сохраните, загрузите обновлённый файл в GitHub — через минуту сайт заработает с общим прогрессом.

После этого: в Профиле у администратора (после включения PIN) появится кнопка **«Прогресс всех пользователей»** — список всех, кто пользовался приложением, с их XP, значками и результатами тестов по каждому курсу. Нажатие на пользователя открывает детальную карточку с результатами по каждому модулю.

**Важно про безопасность:** правила в `firestore.rules.txt` открытые (без сложной авторизации) — это осознанный компромисс для простоты. Подходит для небольшого внутреннего проекта, где ссылку на приложение знают только свои сотрудники. Если приложением будут пользоваться посторонние или данные станут чувствительными — потребуется добавить полноценную Firebase Authentication (могу помочь отдельно).

## Выгрузка результатов в Google Таблицу

1. Создайте новую Google Таблицу (**sheets.google.com**) → назовите первый лист, например, «Результаты» → в первой строке впишите заголовки: `Имя | Курс | Модуль | Баллы | Из скольки | Критично_ок | Дата`.
2. В таблице: **Расширения → Apps Script**.
3. Удалите код-заглушку, вставьте вместо него содержимое файла `apps-script.txt`.
4. Нажмите **Развернуть (Deploy) → New deployment** → тип **Web app**. Execute as: **Me**. Who has access: **Anyone**. Нажмите **Deploy** и разрешите доступ (это ваш собственный скрипт).
5. Скопируйте появившийся URL (заканчивается на `/exec`).
6. Откройте `sheets-config.js`, вставьте этот URL вместо `null`.
7. Сохраните и загрузите файл в GitHub.

После этого:
- Кнопка **«📤 Выгрузить в Таблицу»** в карточке пользователя (админ-панель → выбрать пользователя) отправит в Таблицу все его результаты тестов.
- Результаты **итогового экзамена** курса «Итоговая аттестация мастера смены» отправляются в Таблицу автоматически сразу после прохождения — ничего нажимать не нужно.

## Что добавлено в этой версии
- **Информационный портал** (вкладка «Портал») — справочные материалы и чек-листы, не завязанные на прогресс/геймификацию: разграничение мастер/технолог, чек-листы приёма и закрытия смены, ККТ ХАССП, стоп-факторы, действия при нештатных ситуациях. Редактируется так же, как курсы.
- **Курс «Итоговая аттестация мастера смены»** — повторение ключевых тем + финальный экзамен на 15 вопросов (проходной балл 85%, критические вопросы ОТ/ХАССП/стоп-факторы — только 100%).
- **Идентификация пользователя** — при первом запуске приложение спрашивает имя, чтобы наставник мог отличать пользователей в статистике.
- **Админ-панель** — просмотр прогресса всех пользователей и экспорт в Google Таблицу.

## Смена PIN администратора
В файле `app.js` найдите `if (pin !== "1234")` и замените на нужный PIN.
