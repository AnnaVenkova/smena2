# Смена+ на Supabase — пошагово

Вместо Firebase: один проект Supabase, таблицы видны как Excel, файлы — в Storage.

---

## Шаг 1. Создать проект

1. Зайдите на https://supabase.com → **Start your project** / **New project**
2. Имя: например `smena-plus`, задайте пароль БД (сохраните), регион ближе к вам
3. Дождитесь создания (1–2 минуты)

---

## Шаг 2. SQL-схема

1. В меню слева: **SQL Editor** → **New query**
2. Откройте файл `supabase-setup.sql`, скопируйте **всё**, вставьте в редактор
3. Нажмите **Run** (или Ctrl+Enter)
4. Должно быть Success без красных ошибок

Так создаются таблицы `profiles`, `app_content`, правила доступа и bucket для файлов.

---

## Шаг 3. Ключи API

1. **Project Settings** (шестерёнка) → **API**
2. Скопируйте:
   - **Project URL**
   - **anon public** ключ
3. Откройте `supabase-config.js` и вставьте:

```js
const SUPABASE_CONFIG = {
  url: "https://ВАШ_ПРОЕКТ.supabase.co",
  anonKey: "eyJhbGciOi..."
};
```

---

## Шаг 4. Authentication

1. **Authentication** → **Providers** → **Email** → включён
2. **Выключите** «Confirm email» (Confirm email → OFF), иначе сотрудники не войдут без почты
3. **Authentication** → **Providers** → можно отключить публичную регистрацию:
   - Settings → Auth → **Allow new users to sign up** → OFF  
   (создание только через админку / Dashboard)

### Первый администратор

1. **Authentication** → **Users** → **Add user** → Create new user  
   - Email: ваш рабочий email  
   - Password: надёжный пароль  
   - Auto Confirm: **ON**
2. **SQL Editor** → выполните (подставьте свой email):

```sql
update public.profiles
set role = 'admin', name = 'Администратор'
where id = (select id from auth.users where email = 'ВАШ@EMAIL.ru');
```

Если строки profiles ещё нет:

```sql
insert into public.profiles (id, login, name, role)
select id, email, 'Администратор', 'admin'
from auth.users where email = 'ВАШ@EMAIL.ru'
on conflict (id) do update set role = 'admin';
```

## Шаг 5. Создание сотрудников из приложения (Edge Function)

Без этого можно создавать пользователей вручную в **Authentication → Users**  
(email вида `логин@smena.users`, пароль, Auto Confirm ON).

Чтобы кнопка «Создать сотрудника» в админке работала:

### Вариант А — через сайт Supabase (проще)

1. **Edge Functions** → Create function → имя `create-employee`
2. Вставьте код из `edge-functions/create-employee/index.ts`
3. Deploy
4. Аналогично можно задеплоить `delete-employee`

### Вариант Б — через CLI

```bash
npm i -g supabase
supabase login
supabase link --project-ref ВАШ_REF
supabase functions deploy create-employee
supabase functions deploy delete-employee
```

## Шаг 6. Файлы сайта на GitHub

В корень репозитория `smena2` положите (замена):

| Файл | Откуда |
|------|--------|
| `index.html` | из этого архива |
| `cloud.js` | из этого архива |
| `supabase-config.js` | из этого архива (**с вашими url и anonKey**) |
| `app.js` | из этого архива |
| `styles.css` | из этого архива |

Оставьте как были: `data.js`, `access-config.js`, `sheets-config.js`, `manifest.json`, `sw.js`, `icons/`.

**Удалите** (больше не нужны): `firebase-config.js`, старые `firestore.rules.txt`.

```bash
git add index.html cloud.js app.js styles.css supabase-config.js
git rm -f firebase-config.js 2>/dev/null || true
git commit -m "Переход на Supabase"
git push
```

## Шаг 7. Проверка

1. Откройте сайт → код доступа (если включён)
2. Вход: **email и пароль администратора**
3. Профиль → режим администратора должен быть активен
4. **Админ** → создайте сотрудника (логин `ivanov`, имя, пароль)
5. Выйдите → войдите логином `ivanov` и паролем сотрудника
6. Админом загрузите файл во вложения урока

## Где что смотреть в Supabase (удобнее Firestore)

| Данные | Где в Supabase |
|--------|----------------|
| Пользователи Auth | Authentication → Users |
| Прогресс, роли | Table Editor → **profiles** |
| Курсы и портал | Table Editor → **app_content** |
| Файлы | Storage → bucket **content** |

---

## Если что-то не работает

| Симптом | Решение |
|---------|---------|
| «Облако не подключено» | Заполнены `url` и `anonKey` в `supabase-config.js`, файл подключён в `index.html` |
| Неверный логин/пароль | Confirm email выключен; пользователь Auto Confirm |
| Нет прав / RLS | Заново выполните `supabase-setup.sql`; role=admin у вашего профиля |
| Не создаётся сотрудник | Edge Function не задеплоена → создайте вручную User с email `логин@smena.users` |
| Файлы не грузятся | Storage bucket `content` есть, вы вошли как admin |

Firebase можно не удалять — сайт его больше не использует.
