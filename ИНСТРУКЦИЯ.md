# Вложения файлов в Смена+

Готовые файлы — просто замените ими файлы в репозитории.

## 1. Firebase Storage (один раз)

1. [Firebase Console](https://console.firebase.google.com) → проект `smena3-975cd`
2. **Build → Storage**
   - Если ещё не включён: Get started → регион → Done
3. Вкладка **Rules** → вставьте содержимое `storage.rules.txt` → **Publish**

## 2. Замените файлы в репозитории

Скопируйте из этой папки в корень репозитория (замена):

| Файл | Действие |
|------|----------|
| `index.html` | заменить |
| `cloud.js` | заменить |
| `app.js` | заменить |
| `styles.css` | заменить |

```bash
# из папки репозитория, если файлы лежат рядом:
cp путь/к/smena2-files/index.html .
cp путь/к/smena2-files/cloud.js .
cp путь/к/smena2-files/app.js .
cp путь/к/smena2-files/styles.css .

git add index.html cloud.js app.js styles.css
git commit -m "Добавлена загрузка файлов (картинки, PDF, Word, PPT, Excel)"
git push
```

Через 1–2 минуты на https://annavenkova.github.io/smena2/ появится блок **Вложения**.

## 3. Как пользоваться

1. Профиль → Режим администратора → войдите по **email/паролю** Firebase (не PIN)
2. Откройте урок или материал портала → ✏️
3. В блоке **Вложения** → «Добавить файл»
4. После загрузки → **Сохранить**

- Картинки показываются превью (тап — на весь экран)
- PDF, Word, PPT, Excel — список со ссылкой «Открыть»
- Лимит: **25 МБ** на файл

## Если загрузка не работает

1. Вы вошли именно как админ (Firebase email), а не по локальному PIN
2. Правила Storage опубликованы
3. В `index.html` есть строка `firebase-storage-compat.js`
4. F12 → Console — нет ошибки `storage/unauthorized`
